# Haven & Co. — Frontend

React + Vite + TypeScript + Tailwind + Supabase real-estate app.

## Setup

1. Run `supabase/schema.sql` in the Supabase SQL Editor (see root instructions from the assistant).
2. Copy env file and fill keys from **Project Settings → API**:

```bash
cp .env.example .env
```

3. Install and start:

```bash
npm install
npm run dev
```

App runs at http://localhost:5173/
